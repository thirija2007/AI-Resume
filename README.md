# 🤖 AI Resume Analysis

## 📌 Overview

**AI Resume Analysis** is a project designed to evaluate how well a resume matches a specific **Job Description (JD)**. It analyzes the candidate's skills, education, projects, internship experience, certifications, and other relevant information and compares them with the requirements of the targeted job role.

For this project, the target role is **AI Engineer – Fresher**. The resume is evaluated based on the technical skills, responsibilities, qualifications, and experience mentioned in the Job Description.

The analysis achieved an **ATS Score of 92/100**, indicating an excellent match between the resume and the targeted AI Engineer Fresher role.
